# Weblog PT Tah Sung Hung — Tugas 3 Nur Helen Shafira

Weblog akademik mengenai PT Tah Sung Hung yang dibuat berdasarkan Tugas Tutorial 1 Teknik Humas, untuk memenuhi Tugas Tutorial 3.

## Isi
- Profil perusahaan dan bidang usaha
- Interpretasi visi dan misi (bukan pernyataan resmi)
- Ilustrasi struktur fungsional organisasi (bukan struktur resmi)
- Artikel dari press release Tugas 1
- Galeri visual konseptual untuk kampanye komunikasi (bukan dokumentasi nyata)

## Menjalankan
Buka `index.html` langsung di browser. Website statis tanpa dependensi dan build step.

## Publikasi GitHub Pages
1. Buat repository publik baru.
2. Unggah seluruh file pada root repository.
3. Buka Settings → Pages → Build and deployment → Deploy from a branch → `main` dan `/ (root)` → Save.
4. Tunggu publikasi GitHub Pages dan salin URL untuk pengumpulan tugas.
