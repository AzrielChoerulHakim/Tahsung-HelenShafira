# PT Tah Sung Hung — Di Balik Setiap Langkah

Weblog akademik karya **Nur Helen Shafira** (NIM **044543189**) untuk **Tugas Tutorial 3, Teknik Humas, Universitas Terbuka**.

## Arah desain

Desain editorial-industrial dengan tipografi Barlow Condensed + DM Sans + Instrument Serif, kontras hitam/putih hangat/acid green, foto faktual, animasi scroll berperforma ringan, menu mobile aksesibel, dan dukungan reduced motion.

## Rubrik

- **Profil perusahaan:** usaha manufaktur alas kaki, lokasi Brebes, serta arah operasional.
- **Visi dan misi:** interpretasi berdasarkan Tugas 1, bukan kutipan resmi perusahaan.
- **Struktur organisasi:** ilustrasi fungsi umum perusahaan manufaktur, bukan struktur resmi.
- **Berita:** siaran pers Tugas 1 (4 Oktober 2026) dan konsep komunikasi “Produksi Berkualitas dan Berkelanjutan”.
- **Galeri:** poster kampanye konseptual, dokumentasi kunjungan publik tahun 2025, dan dokumentasi lini produksi.
